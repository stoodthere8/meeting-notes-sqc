미팅 노트 스킬 — 실행 시퀀스

"이 미팅 노트 앱으로 보내줘" 요청 시 처리 흐름 요약 스킬은 초안 생성까지만 수행, 공개(승인)는 담당자가 앱에서 직접 처리

요청 응답·결과 스킬이 하는 일 사람이 하는 일 처리 내용(메모)

판단이 필요한 쟁점과 대응 방안

  • 미팅 대화의 외부 AI 전송 가능 여부
    • 판단 이름·업무 내용은 개인정보·영업비밀 가능성 자동 경로는 Claude 분석 방식으로 이름 가리기(가명처리) 적용 불가
    • 극복 사용자가 직접 "보내줘"라고 요청한 대화만 처리 외부 AI 전송 사실 앱 내 고지 시연은 가상 미팅만 사용 직접 붙여넣기 경로는 이름 가리기(참여자N) 옵션 제공
  • 원문의 앱 저장 가능 여부
    • 판단 원문까지 앱에 보관 시 유출 피해 확대 앱에 필요한 정보는 정리 결과뿐
    • 극복 앱에는 요약·결정·액션아이템만 저장 원문은 본인 Drive에만 보관 삭제는 수동
  • AI 추출 할 일의 참여자 직접 전달 가능 여부
    • 판단 담당자·기한 오지정 시 참여자가 의도치 않은 업무 수행 책임이 수반되는 판단
    • 극복 자동 입력은 항상 "초안" 생성 승인 전 비공개 담당자 미지정 시 승인 불가
  • 웹앱의 공개 URL 게시 가능 여부
    • 극복 관리자 비밀번호 인증, 참여자별 초대 링크(해시 저장·재발급), DB 공개 접근 차단
  • 키 유출 및 비용 키는 요청 헤더로만 전송 시간당 30건, 입력 20,000자 제한

개발 과정의 시행착오와 개선

  • 초기 구현: 대화 붙여넣기 방식 앱 실제 요구사항은 "Drive 저장 시 필드 자동 입력" 요구사항 오해석
  • 이후 조치: 자동 수집 경로, 초안함, 신규 미팅 알림 팝업 추가
  • 클라우드 실행 시 G: 드라이브·키 부재로 실패 Drive 커넥터 대체 경로 추가로 해결
  • 경로 차단 시 대체 방안을 하나씩 검증하며 개선

핵심 요약
